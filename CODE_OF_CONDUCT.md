# Code of Conduct

## Our standard

FireLens welcomes contributors of every background and experience level. Be
respectful, constructive, and considerate in issues, pull requests, reviews,
and other project spaces.

Examples of welcome behavior include:

- giving actionable feedback and accepting it gracefully;
- focusing disagreement on ideas and evidence;
- respecting different viewpoints, identities, and levels of experience; and
- taking responsibility, apologizing, and repairing harm when mistakes happen.

Harassment, discrimination, threats, sexualized attention, personal attacks,
doxing, and sustained disruption are not acceptable.

## Enforcement

Project maintainers may edit or remove contributions that violate this code
and may temporarily or permanently restrict participation. Enforcement should
be fair, proportionate, and focused on protecting the community.

Report conduct concerns privately to the maintainer through the contact method
on [Ali Aslanbayli's GitHub profile](https://github.com/aslanbayli). Do not
post sensitive reports in a public issue. Reports will be reviewed as promptly
and confidentially as practical.

This code applies in official project spaces and when someone publicly
represents the project.
